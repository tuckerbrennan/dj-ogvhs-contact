# DJ OGVHS Contact

Public contact page at https://contact.ogvhs.com/, hosted by GitHub Pages from main / (root).

Contact information is published with the owner’s authorization. Formspree endpoint configuration is a public form identifier, not a secret. The recipient account is managed in Formspree. Submission subjects use [DJ OGVHS][Request type] followed by the visitor’s subject. Required fields: request type, sender email, subject, message. No passwords or private backend data are included.

The former Sites contact project is no longer the publishing target after repeated infrastructure deployment failures. This repository is the canonical source for the public contact page.
